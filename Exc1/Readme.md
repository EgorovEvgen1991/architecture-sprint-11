## 2 Опишите проблемные места.
- Microsoft SQL Server нужно обновить что бы поднять производительность. либо перейти на Open source решение например на Postgres
- DWH не сильно подходит для ИИ аналитики(Если верить лекции).Поэтому нужно перейти на DataLakeHouse. К тому же   нужно будет хранить неструктурированые данные по клиентам (снимки и анализы используя новейшее оборудование)
- Проблемы в получении отчетности. В описании к заданию упоминается что есть проблема построения отчетов за заданное время. Из-за большого количества данных и вариантов их  использования.
- Не указана модель распределения доступа к данным ABAC/RBAC. 
- DWH представляет собой "помойку" с данными в которой тяжело ориентироваться. При запросе большого объема данныех из бд теряется производительность. DWH нужно разбить на домены где будет бд как Data product. К каждому Data Product будет своя витрина с правами доступа
- заменить Apache Camel на Apache Kafka, так как Apache Kafka подходит для более высоконагруженных систем, что позволяет лучше интегрировать сервисы  и повысить оперативность доставки данных.
- заменить Power BI на DataLens, что позволит отказаться от проприетарного ПО, оплаты лицензий и отказа от обслуживания, что снизит риски и сэкономит финансы.
